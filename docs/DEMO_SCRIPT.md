# Orrin — 60-second voice demo script

A tight recording flow that shows Orrin is *your* Claude Code, by voice + a screen. Record with
**⌘⇧5** (screen record). Product name is **Orrin**; the wake word is **"Otto"**.

## Before you hit record (30s of prep)
- **Headphones on** (kills speaker→mic echo — the cleanest capture).
- Launch Orrin; open the dashboard (menu bar → Open Dashboard). Wait for **✓ Ready**.
- Put the window where the sidebar + hero + Chat drawer are all visible.
- Speak in a normal pace; pause ~1s after each request so Orrin picks up the turn.

## The flow (~60s)

| # | You say (out loud) | What the viewer sees |
|---|--------------------|----------------------|
| 1 | *"Otto — what can you do?"* | Orb pulses (listening→thinking→speaking); reply streams in the Chat drawer; caption shows your words. |
| 2 | *"Otto, what's the weather and my GitHub activity?"* | Point to the **weather hero** + **GitHub Activity** card — real, live data. |
| 3 | *"Otto, in the clickhouse project, check git status and summarize what's changed."* | Say it, then switch focus — a background workspace runs; the status/mood reacts. |
| 4 | *"Otto, create a file called demo.txt that says hello, and show me a chart of my last five commits by day."* | Real tool calls appear in the chat; a **chart shows in Visuals** (the "screen"). |
| 5 | *"Otto, stop listening."* then *"Otto"* to wake it | Shows hands-free **sleep/wake**; the orb calms (green) then re-arms. |
| 6 | Toggle **🌙/☀️** and click through **Home / Conversations / Visuals / Settings** | Shows the light/dark theme + the whole UI in ~5s. |

## One-liner to open the video with
> "This is Orrin — it wraps the Claude Code I already run, and gives it a voice and a screen.
> Everything you'll see is my real Claude doing the work; I'm just talking to it."

## Tips
- If a reply is long, wait for it to finish before the next line (Orrin mutes the mic while it
  speaks, so it won't hear itself).
- To keep it snappy, prefer short asks; the details show on screen in the chat.
- Mute the mic (menu bar or the listening bar) between takes so ambient noise doesn't trigger it.
- Good closers: "…and it's all my own Claude — my MCP servers, subagents, skills, and permissions,
  just spoken."
